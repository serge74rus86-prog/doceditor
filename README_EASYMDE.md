# Руководство пользователя: Markdown редактор с EasyMDE

## Быстрый старт

### 1. Открытие редактора

1. Запустите Pilot-ICE/ECM
2. Перейдите на новую вкладку
3. Нажмите кнопку **"📝 Markdown редактор"**

### 2. Интерфейс редактора

```
┌─────────────────────────────────────────────────────────────────────┐
│  ℹ️ EasyMDE имеет встроенную панель форматирования                 │
│  👁️ Предпросмотр │ 📋 Копировать HTML │ 📄 PDF │ 🖨️ Печать       │
├──────────────┬──────────────────────────────────────────────────────┤
│              │ [B][I][S]│H1-H6│H▼│""│• 1.│⇥⇤│#│🔗🖼️│📊│─│👁️│◧│  │
│ 📁 Объекты   │ ┌────────────────────────────────────────────────┐  │
│              │ │                                                │  │
│   📄 Документ│ │  # Заголовок                                   │  │
│   ├─ Файл    │ │                                                │  │
│   └─ Папка   │ │  **Жирный текст**                              │  │
│              │ │                                                │  │
│              │ │  - Список                                      │  │
│              │ │    - Вложенный элемент                         │  │
│              │ │                                                │  │
│              │ └────────────────────────────────────────────────┘  │
└──────────────┴─────────────────────────────────────────────────────┘
```

## Основные возможности

### Редактирование Markdown

**EasyMDE** предоставляет визуальную панель инструментов:

| Кнопка | Действие | Результат |
|--------|----------|-----------|
| **B** | Жирный текст | `**текст**` |
| **I** | Курсив | `*текст*` |
| **S** | Зачеркнутый | `~~текст~~` |
| **H1-H6** | Заголовки уровней 1-6 | `# H1`, `## H2`, и т.д. |
| **H** | Переключатель заголовка | Циклическое переключение |
| **" "** | Цитата | `> цитата` |
| **•** | Маркированный список | `- элемент` |
| **1.** | Нумерованный список | `1. элемент` |
| **⇥** | Увеличить отступ списка | Вложенный список (Tab) |
| **⇤** | Уменьшить отступ списка | Выход из вложенности (Shift+Tab) |
| **#** | Многоуровневая нумерация | `1, 1.1, 1.1.1` |
| **🔗** | Вставить ссылку | `[текст](url)` |
| **🖼️** | Вставить изображение | `![описание](url)` |
| **📊** | Таблица | Шаблон таблицы |

### Горячие клавиши

- `Ctrl+B` — Жирный текст
- `Ctrl+I` — Курсив
- `Ctrl+Alt+H` — Заголовок (циклическое переключение)
- `Ctrl+Alt+1` — Заголовок H1
- `Ctrl+Alt+2` — Заголовок H2
- `Ctrl+Alt+3` — Заголовок H3
- `Ctrl+Alt+4` — Заголовок H4
- `Ctrl+Alt+5` — Заголовок H5
- `Ctrl+Alt+6` — Заголовок H6
- `Ctrl+Alt+T` — Таблица
- `Tab` — Увеличить отступ списка (вложенность)
- `Shift+Tab` — Уменьшить отступ списка

### Работа с заголовками

Редактор поддерживает два способа работы с заголовками:

#### Быстрые кнопки H1-H6

На панели инструментов доступны отдельные кнопки для каждого уровня заголовка:
- **H1** - Главный заголовок документа
- **H2** - Заголовок раздела
- **H3** - Подраздел
- **H4-H6** - Дополнительные уровни вложенности

#### Циклическое переключение

Используйте кнопки `H`, `H▼`, `H▲` для циклического переключения между уровнями заголовков.

### Многоуровневые списки

#### Вложенные списки

Для создания вложенных списков используйте:
- Кнопки **⇥** (увеличить отступ) и **⇤** (уменьшить отступ)
- Горячие клавиши `Tab` и `Shift+Tab`

Пример:
```markdown
- Основной элемент
  - Вложенный элемент
    - Ещё глубже
  - Возврат к предыдущему уровню
- Снова основной уровень
```

#### Многоуровневая нумерация

Кнопка **#** включает многоуровневую нумерацию для нумерованных списков:

```markdown
1. Первый раздел
   1.1. Подраздел
      1.1.1. Детали
   1.2. Ещё подраздел
2. Второй раздел
```

В режиме предпросмотра такие списки отображаются с автоматической нумерацией вида `1, 1.1, 1.1.1`.

### Экспорт и печать

#### 📄 Экспорт в PDF

1. Нажмите кнопку **"📄 Экспорт в PDF"** на панели инструментов
2. Выберите место сохранения файла
3. Документ будет сохранен в формате PDF с сохранением форматирования

PDF включает:
- Все заголовки и текст
- Списки (включая многоуровневые)
- Таблицы и изображения
- Фоновые цвета и стили

#### 🖨️ Печать

1. Нажмите кнопку **"🖨️ Печать"** на панели инструментов
2. Откроется диалог печати браузера
3. Выберите принтер или сохраните как PDF через системный диалог

Диалог печати позволяет:
- Выбрать принтер
- Настроить количество копий
- Изменить ориентацию страницы
- Предварительный просмотр перед печатью

### Интеграция с Обозревателем документов

#### 📋 Карточка элемента с Markdown

При выборе `.md` или `.markdown` файла в **Обозревателе документов** Pilot-ICE, в карточке элемента автоматически появляется дополнительная вкладка **"📝 Markdown"**.

**Вкладка "Свойства объекта":**
- Отображает имя, ID и тип объекта
- Показывает все атрибуты выбранного элемента
- Стандартная информация Pilot

**Вкладка "Markdown":**
- **Режим просмотра** (по умолчанию) - отрендеренный HTML с правильным форматированием
- **Режим редактирования** - текстовый редактор для изменения Markdown контента
- Кнопка "✏️ Редактирование" для переключения между режимами

**Как использовать:**
1. Откройте Обозреватель документов в Pilot-ICE
2. Выберите файл с расширением `.md` или `.markdown`
3. В правой панели появятся две вкладки
4. Переключайтесь между свойствами объекта и Markdown контентом
5. Нажмите "✏️ Редактирование" для внесения изменений

**Поддерживаемые типы объектов:**
- `document` - документы
- `file` - файлы
- `section` - разделы

Можно настроить дополнительные типы через конфигурацию в коде.

#### 🆕 Создание нового Markdown файла

Если в базе Pilot нет Markdown файлов, их можно создать прямо из контекстного меню:

1. В **Обозревателе документов** выберите папку или раздел (контейнер)
2. Правая кнопка мыши → **"📝 Создать Markdown файл"**
3. Введите имя файла в диалоговом окне
4. Нажмите OK (расширение `.md` добавится автоматически)
5. Откроется стандартный диалог создания объекта **ЕСМ Документ** (`ecm_doc`)
6. Заполните необходимые атрибуты и сохраните
7. Файл автоматически откроется в карточке элемента с Markdown редактором

**Тип создаваемого объекта:** `ecm_doc` (документ ЕСМ)

**Поддерживаемые типы для отображения Markdown редактора:**
- `ecm_doc` - документ ЕСМ (основной тип)
- `document` - обычный документ
- `file` - файл
- `section` - раздел

**Преимущества:**
- ✅ Файл создается непосредственно в базе данных Pilot
- ✅ Автоматическое добавление расширения `.md`
- ✅ Использование стандартного диалога Pilot для заполнения атрибутов
- ✅ Мгновенное открытие созданного файла для редактирования
- ✅ Не нужно покидать Обозреватель документов

### Работа с объектами Pilot

#### Вставка атрибутов объекта

1. В дереве объектов (слева) выберите объект
2. Правая кнопка мыши → **"Добавить атрибуты в редактор"**
3. Атрибуты объекта вставятся в редактор в формате:

```markdown
## Атрибуты объекта: Документ
```
Name "Чертеж детали"
Author "Иванов И.И."
Date "06.03.2026"
```
```

#### Копирование имени объекта

1. Выберите объект в дереве
2. Правая кнопка мыши → **"Копировать имя"**
3. Имя скопировано в буфер обмена

## Режимы работы

### 1. Режим редактирования (по умолчанию)

- Редактирование текста в формате Markdown
- Визуальная панель инструментов
- Поддержка синтаксиса Markdown

### 2. Режим предпросмотра

Нажмите **"👁️ Предпросмотр"** для переключения:

- Отображение HTML-версии
- Генерация через Markdig
- Все форматирование применено

## Примеры использования

### Создание документа

```markdown
# Отчёт по проекту

## Введение

Это **пример документа** в формате Markdown.

### Основные разделы

1. Первый раздел
2. Второй раздел
3. Третий раздел

## Таблица данных

| Параметр | Значение | Ед. изм. |
|----------|----------|----------|
| Длина    | 100      | мм       |
| Ширина   | 50       | мм       |
| Высота   | 25       | мм       |

## Примечания

> Важно: Проверьте все размеры перед утверждением.
```

### Вставка атрибутов из Pilot

1. Откройте редактор
2. В дереве объектов найдите нужный документ
3. ПКМ → "Добавить атрибуты в редактор"
4. Атрибуты вставятся в текущую позицию курсора

## Копирование HTML

Для использования Markdown за пределами Pilot:

1. Напишите текст в редакторе
2. Нажмите **"📋 Копировать HTML"**
3. Вставьте HTML в нужное место

## Очистка редактора

Нажмите **"🗑️ Очистить"** для удаления всего содержимого.

## Поддерживаемый синтаксис Markdown

### Заголовки
```markdown
# Заголовок 1
## Заголовок 2
### Заголовок 3
#### Заголовок 4
```

### Текст
```markdown
**жирный текст**
*курсив*
~~зачеркнутый~~
```

### Списки
```markdown
- Маркированный список
- Элемент 1
- Элемент 2

1. Нумерованный список
2. Первый пункт
3. Второй пункт
```

### Ссылки и изображения
```markdown
[текст ссылки](https://example.com)
![описание изображения](https://example.com/image.png)
```

### Код
```markdown
Встроенный `код` в тексте

```язык
блок кода
с подсветкой синтаксиса
```
```

### Цитаты
```markdown
> Это цитата
> с несколькими
> строками
```

### Таблицы
```markdown
| Заголовок 1 | Заголовок 2 |
|-------------|-------------|
| Ячейка 1    | Ячейка 2    |
| Ячейка 3    | Ячейка 4    |
```

## Советы

1. **Используйте панель инструментов** — быстрее, чем запоминать синтаксис
2. **Горячие клавиши** — ускоряют работу с форматированием
3. **Предпросмотр** — проверяйте, как будет выглядеть документ
4. **Атрибуты Pilot** — быстро вставляйте метаданные объектов

## Возможные проблемы

### Редактор не открывается
**Решение:** Убедитесь, что установлен WebView2 Runtime

### Текст не форматируется
**Решение:** Выделите текст перед применением форматирования

### Объекты Pilot не отображаются
**Решение:** Убедитесь, что открыт проект в Pilot-ICE
