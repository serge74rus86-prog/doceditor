# Улучшения карточки объекта Markdown

## Что было сделано

### 1. Сервис временных файлов (TempFileService)

Создан новый сервис `ITempFileService` для упрощения работы с Markdown файлами:

**Основные функции:**
- Хранение Markdown контента во временной папке (`%TEMP%\PilotMarkdownModule\TempFiles`)
- Автоматическая инициализация временного файла из объекта Pilot
- Автосохранение изменений во временный файл при каждом изменении
- Сохранение изменений обратно в объект Pilot по кнопке "Сохранить"
- **Проверка существования файла** - не перезаписывает существующий временный файл

**Преимущества:**
- ✅ Не нужно напрямую работать с атрибутами объекта при каждом изменении
- ✅ Быстрое автосохранение без обращения к базе данных Pilot
- ✅ Возможность отмены изменений до сохранения
- ✅ Простая архитектура - один файл = один объект
- ✅ **Временные файлы сохраняются между сеансами**

### 2. Обновленная ViewModel (MarkdownDetailsViewModel)

**Новые возможности:**
- Использование `ITempFileService` для работы с файлами
- Отслеживание несохраненных изменений (`HasUnsavedChanges`)
- Команда сохранения (`SaveCommand`) с проверкой наличия изменений
- Автоматическое сохранение во временный файл при изменении контента

**Изменения:**
```csharp
// Было
private void LoadMarkdownContent() { ... }

// Стало
private void InitializeTempFile() { ... }
private void SaveToTempFile() { ... }
private void SaveToPilot() { ... }
```

### 3. Обновленный интерфейс (MarkdownDetailsTabView)

**Новые элементы:**
- Кнопка "💾 Сохранить" на панели инструментов
- Использование полноценного редактора EasyMDE вместо простого TextBox
- Интеграция с `LiveMarkdownEditor` для WYSIWYG редактирования

**Изменения в XAML:**
```xml
<!-- Было: простой TextBox -->
<TextBox Text="{Binding MarkdownContent}" ... />

<!-- Стало: полноценный EasyMDE редактор -->
<views:LiveMarkdownEditor 
    MarkdownText="{Binding MarkdownContent}"
    IsEditMode="True" />
```

### 4. Интеграция с MEF

**Регистрация сервиса:**
```csharp

```

**Обновленный конструктор провайдера:**
```csharp

    IObjectsRepository repository,
```

### 5. Убрано ограничение на расширение файла

**Изменения в MarkdownDetailsViewProvider:**
- ❌ **Удалена проверка** `HasMarkdownContent()` на наличие `.md` или `.markdown` расширения
- ✅ **Вкладка Markdown теперь отображается всегда** для поддерживаемых типов объектов
- ✅ **Временный файл создается автоматически** при первом открытии карточки
- ✅ **Поддерживаемые типы:** `ecm_doc`, `document`, `file`, `section`

**Было:**
```csharp
// Проверяем расширение файла

    return null;  // Вкладка не показывается
```

**Стало:**
```csharp
// Всегда создаем вкладку Markdown для поддерживаемых типов
var viewModel = new MarkdownDetailsViewModel(...);
return view;  // Вкладка показывается всегда
```

## Как это работает

### Поток данных:

1. **Открытие карточки объекта (любого поддерживаемого типа):**
   ```
   Pilot Object (ecm_doc/document/file/section)
                → MarkdownDetailsViewProvider.GetDetailsView()
                → TempFileService.InitializeFromPilotObject()
                → Проверка: временный файл уже существует?
                  - ДА: используем существующий файл
                  - НЕТ: создаем новый временный файл
                → Загружается контент
                → Отображается вкладка Markdown с EasyMDE редактором
   ```

2. **Редактирование:**
   ```
   Пользователь печатает → MarkdownContent property setter
                         → Auto-save во временный файл
                         → HasUnsavedChanges = true
                         → Обновляется предпросмотр
   ```

3. **Сохранение:**
   ```
   Нажатие "Сохранить" → SaveCommand.Execute()
                       → TempFileService.SaveToPilotObject()
                       → IObjectModifier.Edit(obj)
                       → builder.SetAttribute("Content", content)
                       → objectModifier.Apply()
                       → HasUnsavedChanges = false
   ```

### Структура временных файлов:

```
%TEMP%\PilotMarkdownModule\TempFiles\
├── {guid-object-1}.md
├── {guid-object-2}.md
└── {guid-object-3}.md
```

Каждый файл соответствует одному объекту Pilot и содержит его Markdown контент.

## Преимущества новой архитектуры

### Для пользователя:
1. **Быстрое редактирование** - изменения сохраняются мгновенно во временный файл
2. **Полноценный редактор** - EasyMDE с панелью инструментов, подсветкой синтаксиса
3. **Контроль сохранения** - явная кнопка "Сохранить" для записи в базу Pilot
4. **Индикация изменений** - можно видеть, есть ли несохраненные изменения

### Для разработчика:
1. **Простая архитектура** - четкое разделение ответственности
2. **Легкая отладка** - можно посмотреть содержимое временных файлов
3. **Тестируемость** - сервисы можно тестировать отдельно
4. **Расширяемость** - легко добавить новые функции (автосохранение, история изменений)

## Технические детали

### Используемые API Pilot SDK:

```csharp
// Получение объекта
var obj = _repository.GetType().GetMethod("GetCachedObject")
                     .Invoke(_repository, new object[] { objectId });

// Модификация объекта
var builder = objectModifier.Edit(obj);
builder.SetAttribute("Content", content);
objectModifier.Apply();
```

### Обработка ошибок:

- Если объект не найден - показывается сообщение об ошибке
- Если сохранение не удалось - отображается диалог с описанием ошибки
- Все операции логируются через `System.Diagnostics.Debug.WriteLine`

### Производительность:

- Временные файлы хранятся в быстром доступе (%TEMP%)
- Автосохранение происходит синхронно при изменении (быстро, т.к. запись в локальный файл)
- Сохранение в Pilot происходит только по запросу пользователя

## Тестирование

Для проверки работы:

1. Соберите проект: `dotnet build`
2. Закройте Pilot-ICE (если открыт)
3. Скопируйте `PilotMarkdownModule.ext2.dll` в папку расширений Pilot
4. Откройте Pilot-ICE
5. Выберите **любой объект** поддерживаемого типа (`ecm_doc`, `document`, `file`, или `section`)
   - **Не важно**, какое расширение у файла (.md, .txt, .docx, или вообще без расширения)
6. В правой панели появятся две вкладки: "📋 Свойства объекта" и "📝 Markdown"
7. Перейдите на вкладку "📝 Markdown"
8. Нажмите "✏️ Редактирование" для включения редактора EasyMDE
9. Внесите изменения - они автоматически сохранятся во временный файл
10. Нажмите "💾 Сохранить" для записи изменений в базу Pilot
